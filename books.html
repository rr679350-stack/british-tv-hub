Reading Order Guides

Cosy · Modern

Start with The Thursday Murder Club, then read the series in publication order — each book builds on the last.

Atmospheric · Contemporary
Ann Cleeves

Two series worth knowing: Vera Stanhope (start with The Crow Trap) and Shetland (start with Raven Black).

Clever · Meta
Anthony Horowitz

Start with Magpie Murders for the Susan Ryeland series, or The Word Is Murder for the Hawthorne series.

Character-Driven
Elly Griffiths (Ruth Galloway)

Start with The Crossing Places — the series is best read in order as relationships evolve across books.
